# Environmental engineering ideas for 2026–2027

Research updated October 23, 2026. Three alternatives combining hardware and machine learning with direct habitat restoration or removal of existing pollution. No dredging project is included. No project has been selected, built or experimentally validated.

These are planning allowances, not delivered quotations or predicted results. Each detailed card includes instruments, repeated testing, fair entry, protection/display supplies and contingency. An existing computer, P2S printer and laser cutter are available; specialist lab equipment or a permitted field site is not assumed. The two camera allowances remove an otherwise unconfirmed assumption of access to a phone camera. All alternatives must stay within a $1,200 total cap.

## What would make a project worth pursuing

The student must physically improve the measured condition or recovery outcome, and the learned method must beat a competent simple alternative. Accurate detection, a forecast, or a high training score does not satisfy that requirement. Each idea has explicit stop criteria. Original physical intervention data are essential; there is no verified public dataset that labels the action consequences of these particular devices.

The recommendation is to investigate **cool-water refuges first overall** and **seagrass retention first if a marine application is essential**. Neither is a confirmed novel invention. The possible contribution is a narrowly defined, independently tested improvement over established engineering. Competition advancement and publication cannot be predicted from an idea description.
